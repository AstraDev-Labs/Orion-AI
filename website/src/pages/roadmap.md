# Roadmap

Orion is built by one developer, so priorities follow what alpha testers hit most. This is the current plan, not a promise of dates. Have an idea? Add it to the [wishlist](/wishlist).

## Now: stabilising the alpha

- Fix the bugs alpha testers report, starting with setup on fresh PCs, voice and slow replies.
- Test the installer across more Windows machines and hardware.
- Code-sign the installer so Windows stops showing the SmartScreen warning.

## Next

- A settings screen for everything that still needs a config file (voice, model choice, language).
- Faster and more accurate voice on machines with a supported GPU.
- Better memory tools: see, edit and forget memories visually.
- Google account connection (waiting on Google's app verification).

## Later

- macOS and Linux installers.
- More connections and a simpler way to add your own tools.
- A stable 1.x release.
