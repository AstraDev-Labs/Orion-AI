## The tray icon

Orion lives in the system tray, next to the clock. If you don't see it, click the **^** arrow to show hidden icons.

- **Click** the icon to open Orion.
- **Right-click** for the menu:

| Item | What it does |
| --- | --- |
| Open Orion | Shows the window |
| Status line | Whether the assistant is starting, ready or has a problem |
| Show actions when I copy text | Pops up quick actions (summarise, translate…) when you copy text. Off by default |
| Check for updates / Update now | Checks GitHub for a new version, or installs one that's ready |
| Check for updates automatically | Checks every few hours. On by default |
| Start with Windows | Opens Orion quietly in the tray when you sign in |
| Quit Orion | Stops Orion and its assistant server completely |

## Updates

When a new version is released, Orion shows a notification in the app. Click **Update now** (or use the tray menu). Orion downloads the update, checks it's signed by Orion's release key, installs it and reopens by itself. Your settings, memories and models are kept.

An update that isn't correctly signed is refused and never run.

You can also update by downloading the latest installer from the [download page](/download) and running it over your current install.

## Startup

Turn on **Start with Windows** in the tray menu to have Orion ready when you sign in. It starts in the tray without opening the window.
