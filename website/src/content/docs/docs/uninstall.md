---
title: Uninstall
description: Remove Orion and choose what to delete.
---

1. Quit Orion from the tray menu.
2. Open **Settings → Apps → Installed apps**, find **Orion**, and choose **Uninstall**.
3. Choose what to remove. Ticked items are deleted:

| Option | Ticked by default | Notes |
| --- | --- | --- |
| Orion's Python environment and tools | Yes | |
| AI models Orion downloaded | Yes | Only models Orion setup pulled |
| Speech recognition and voice models | Yes | Whisper and Kokoro, about 500 MB |
| Ollama, the local AI engine | Yes | Shown only if Orion installed it |
| Node.js | Yes | Shown only if WhatsApp was installed |
| uv, the Python package manager | Yes | Shown only if Orion installed it |
| Your settings, memories and conversations | **No** | Also removes linked accounts and saved keys |

Anything that was on your PC before Orion, such as an Ollama or AI models you already had, is never removed.

Leave **your settings, memories and conversations** unticked to keep them for a reinstall. Deleting them can't be undone.
