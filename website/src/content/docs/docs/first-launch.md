## The Core

Orion opens on **The Core**, the main conversation screen. Type a message and press Enter, or turn on the microphone with the **Auditory** button in the top bar (see [Talking to Orion](/docs/voice)).

Try:

- "What's the weather in Chennai?"
- "Open Spotify and play some lo-fi."
- "Set the volume to 30 percent."
- "Remember that my sister's birthday is on 12 March."
- "Remind me to call the bank at 5 pm."

## Screens

The top bar switches screens. You can also press a key:

| Key | Screen | What it's for |
| --- | --- | --- |
| 1 | The Core | Talk to Orion |
| 2 | Discourse | Conversation history |
| 3 | Delegates | Agents working on longer tasks |
| 4 | Recollection | What Orion remembers |
| 5 | Reckoning | Usage and performance |
| 6 | Governance | Pending approvals and rules |
| 7 | The Council | Models |
| 8 | Data console | Settings and configuration |
| 9 | The Chronicle | Activity log |
| 0 | Anatomy | How Orion is put together |
| W | Workflow | Automations |
| C | Connections | Link services such as WhatsApp or email |

Press **Ctrl + K** to open the command palette from anywhere.

## Closing the window

Closing the window keeps Orion running in the system tray so reminders and messages keep working. To quit completely, right-click the tray icon and choose **Quit Orion**. See [Tray, updates and startup](/docs/tray-and-updates).
